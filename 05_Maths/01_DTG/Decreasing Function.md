# Decreasing Function

Let $A,B \subseteq \mathbb{R}$ be two [[Subset]]s of $\mathbb{R}$ and $f:A\to B$ be a [[Function]].

- & We say that:
	- $f$ is decreasing if $f(x)\geq f(y)|\forall x>y$.
	- $f$ is strictly decreasing if $f(x)>f(y)|\forall x>y$

If a [[Function]] is strictly increasing or decreasing, then it must be [[Injective]].
