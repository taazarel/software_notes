# Partition

A collection of nonempty [disjointed](Disjoint.md) [[Subset]]s, $A_{n}$, of the set S, that have S as their [[Union of Sets]].
This can be expressed mathematically as:
1. $A_{n}\neq \varnothing$ for $n \in I$ where $I$ is an index [[Set]].
2. $A_{n}\cap A_{m}=\varnothing$ when $n \neq m$
3. $\bigcup_{n\in I} A_{n}=S$

We can use every partition of a set to form an [[Equivalence Relation]], just as we could form a partition with such a relation.
