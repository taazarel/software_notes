# Lexicographic Ordering

Given a [[Cartesian Product]] $A_{1}\times A_{2}$, the [[Lexicographic Order]] is defined as pair $(a_{1},a_{2})$ being smaller than pair $(b_{1},b_{2})$ if the first element is smaller $a_{1}<b_{1}$, OR if the first element is equal $a_{1}=b_{1}$ and the second element is smaller $a_{2}<b_{2}$.

- $ This can also be written as the mathematical expression:
$$
(a_{1},a_{2})\prec(b_{1},b_{2})\quad|\quad (a_{1}\prec b_{1}) \lor ((a_{1}=b_{1}) \land (a_{2}\prec b_{2}))
$$
