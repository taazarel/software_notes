# Equivalence Class

If R is an [[Equivalence Relation]] on [[Set]] A, then the set of all elements related to $a \in A$ is called the [[Equivalence Class]] of a.
It is denoted by $[a]_{R}$, but if we are only using one relation, we can shorten it to just $[a]$.

- $ So if R is an [[Equivalence Relation]] on [[Set]] A, then the [[Equivalence Class]] of the element a is
$$
[a]_{R}=\{ s|(a,s)\in R \}
$$

If $b \in [a]_{R}$ then the element b is called **representative** of the [[Equivalence Class]] $[a]_{R}$.[^1]

Ergo an equivalence class is a tool to find all pairs which contains a specific element in a given [[Equivalence Relation]]. It does not actually matter what the criteria of the [[Relation]] is.

## Theorem 2 (9.5.4 in [Ros])

Let R be an [[Equivalence Relation]] on the [[Set]] S. The [[Equivalence Class]]es of R will form a [[Partition]] of S. 
Vice versa, given a partition $\{ A_{n}|n\in I \}$ of the set S, there exists an equivalence relation R that has the sets $A_{n},n\in I$ as its [[Equivalence Class]]es.

[^1]: Note that any element which exists in the class can be used, there is nothing special about the element b.
