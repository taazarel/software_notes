# Function

A function from [[Set]] A to [[Set]] B is an assignment of exactly one element b in B to each element of A.
This is denoted by $f(a)=b$ if the element $b \in B$ is assigned to $a \in A$ by the function f.
We can also generally denote $f: A \to B$ when f is a function from A to B.

## Wording
Let $f:A\to B$ be a function. We then say that:
- A is the domain of f.
- B is the codomain of f.
- if $f(a)=b$ then 
	- b is the image of a, and
	- a is the preimage of b
- The set of all images of a, is called the image of f, or the "range". It is denoted by: $f(A):=\{ f(a)|a\in A \}$.
