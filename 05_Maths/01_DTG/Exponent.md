# Exponential Functions

For any positive real number $b \in \mathbb{R}_{+}$ we can define an exponential function with base $b$ as $f_{b}(x)$.
For a natural number $n$ it is defined as $f_{b}(n)=b^{n}=b\dots b$.

## Identities
$$
b^{x+y}=b^{x}b^{y}, \quad (b^{x})^{y} = b^{xy}
$$
