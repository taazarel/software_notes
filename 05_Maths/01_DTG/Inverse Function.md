# Inverse Function

Let $f:A\to B$ be a [[Bijective]] [[Function]]. The inverse function $f^{-1}:B\to A$ is the function that assigns each element $b\in B$ the unique element $a \in A$ for which $f(a)=b$ b is the image. 
- $ Therefore $f^{-1}(b)=a$ if and only if $f(a)=b$.
